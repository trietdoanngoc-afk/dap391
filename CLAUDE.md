## Project Overview

Bank Customer Churn Prediction system for 35 Vietnamese banks. Analyzes app reviews from App Store, Google Play, and Facebook to predict customer churn using a Random Forest model (93.9% accuracy). Data stored in TiDB Cloud, served via FastAPI backend, visualized through static HTML dashboard and Streamlit app.

## Architecture

### Data Pipeline Flow
```
Crawlers (App Store/Google Play/Facebook)
  ↓
Raw Reviews (data/raw/)
  ↓
Preprocessing Pipeline (4 steps: clean → encode → outliers → features)
  ↓
Model Training (Random Forest with noise injection)
  ↓
Two Output Paths:
  1. API Predictions (api.py) → Static Dashboard (dashboard/index.html)
  2. Live Analytics (app.py) → Streamlit Dashboard
```

### Three Main Entry Points

1. **`main.py`** - Data collection orchestrator
   - Runs all crawlers in parallel
   - Adds synthetic customer features (age, balance, credit_score, etc.)
   - Pushes to TiDB Cloud database
   - Saves local CSV/Excel backups

2. **`api.py`** - FastAPI prediction service
   - Loads trained model from `models/rf_churn_model.pkl`
   - `/predict` endpoint: Real-time churn prediction
   - `/api/stats/*` endpoints: Live database statistics
   - `/api/customer-action` endpoint: Track staff actions (mark processed, notes)

3. **`app.py`** - Streamlit interactive dashboard
   - Pulls live data from TiDB Cloud
   - 6 interactive charts with filters
   - Bank selection and dynamic metrics

### Dashboard Architecture

**Two separate dashboards** (not connected):

- **Static HTML** (`dashboard/index.html`):
  - Uses pre-aggregated `dashboard/data.json` (332KB)
  - Generated by `export_dashboard_data.py`
  - Calls FastAPI `/predict` for new predictions
  - Chart.js visualizations, fully Vietnamese, no emoji

- **Streamlit** (`app.py`):
  - Live database queries with caching (1 hour TTL)
  - Plotly interactive charts
  - Bank filtering and chart selection

## Critical Technical Details

### Feature Engineering (18 features total)

The model uses these derived features beyond raw inputs:
- `balance_per_product` = balance / max(1, products_number)
- `tenure_age_ratio` = tenure / max(1, age)
- `is_high_value` (VIP) = 1 if (balance > 7B VND AND credit_score > 600) else 0
- `review_month`, `review_day_of_week` (temporal features)
- Platform one-hot encoding: `platform_app_store`, `platform_facebook`, `platform_google_play`

**VIP Threshold**: 7,000,000,000 VND (7 billion) is hardcoded in `api.py:92` and used consistently across prediction logic.

### Noise Injection Strategy

Model training (`train_model.py`) intentionally injects 5-7% label noise to prevent overfitting on rating alone:
- 5% of churned customers → flipped to "stayed" (high balance/tenure override)
- 7% of stayed customers → flipped to "churned" (competitor sensitivity)

This reduces accuracy from 99%+ to 93.9% but creates a more realistic, robust model. **Do not "fix" this** - it's intentional design documented in lines 95-135 of `train_model.py`.

### Database Connection

TiDB Cloud (MySQL-compatible) with SSL:
- Config in `config.py` → `TIDB_CONFIG`
- Requires `isrgrootx1.pem` certificate file in project root
- Connection string: `mysql+pymysql://` for FastAPI, `mysql+mysqlconnector://` for data loading
- Table: `Bank_Churn_Data.Sentify`

## Bank Configuration

All 35 Vietnamese banks configured in `config.py`:
- `BANKS_ALL` - List of bank names (alphabetical)
- `BANK_APPS_IOS` - App Store IDs (int or None)
- `BANK_APPS_GOOGLE` - Google Play package names (str)

Bank names are **label-encoded** (0-34) in the model. The encoding is alphabetical: ABBank=0, ACB=1, ..., VietinBank=34.

## Preprocessing Pipeline

Four sequential transformers in `utils/preprocessing.py`:

1. **DataCleaner**: Drop nulls, duplicates, invalid dates
2. **CategoricalEncoder**: Label encode bank_name, sex, platform
3. **OutlierHandler**: Winsorize balance, age, credit_score (1st-99th percentile)
4. **FeatureEngineer**: Create derived features (balance_per_product, tenure_age_ratio, is_high_value, temporal)

**No scaling applied** - Random Forest doesn't require it.
